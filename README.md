# Smart Answering Research System – Frontend

A modern frontend application for the **Smart Answering Research System**, built to provide a seamless user experience for a **RAG-based chatbot that gives answers from research papers**, designed for academic research and learning.

---

## 🚀 Project Overview

The frontend enables users to interact with a **research-oriented answering system** that delivers **authentic, citation-backed responses**. It supports both **text-based and voice-based queries**, making research more accessible and efficient for students and researchers.

---

## ✨ Key Features

- 🤖 **RAG-Based Chatbot Interface**
- 🎙️ **Voice Chat Support**
- 🔍 **Simple & Deep Query Interaction**
- 🕘 **Chat History View**
- 🔐 **Authentication-Ready UI**
- 📱 **Responsive & User-Friendly Design**

---

## 🛠️ Tech Stack

- **React.js**
- **JavaScript / JSX**
- **CSS / Tailwind (if applicable)**
- **API Integration with FastAPI Backend**

This repository contains **only the frontend code** for the Smart Answering Research System.  
The backend (FastAPI, RAG pipeline, GROBID, Gemini integration) is maintained separately.
